# TableCSV

Open `.csv` files as readable tables inside your vault.

![TableCSV screenshot](./images/screenshot.png)

## Features

- Open any CSV file as a clean table view
- Sticky header row for easier scrolling
- Simple text filter to narrow rows by cell text
- Works fully offline (no network requests)

## How to use

1. Install **TableCSV** from Community plugins and enable it
2. Open a `.csv` file from the file explorer
3. Browse the table view
4. Type in the filter box at the top to narrow matching rows

## Tips

- Best for quick viewing and searching
- Very large CSV files may take longer to render
- For heavy editing, use a spreadsheet app, then reopen the file here to review
