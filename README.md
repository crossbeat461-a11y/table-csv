# TableCSV

Open `.csv` files as readable tables inside your vault.

## Features

- Open any CSV file as a clean table view
- Sticky header row for easier scrolling
- Simple text filter to narrow rows
- Works offline (no network requests)

## How to use

1. Install and enable **TableCSV**
2. Open a `.csv` file from the file explorer
3. Use the filter box at the top to search cell text

## Notes

- Large CSVs may be slower to render
- For heavy editing, use a spreadsheet app and keep this plugin for quick viewing
